**What it does**
Inbound lead-routing and instant meeting-booking platform ("Concierge") that qualifies web-form leads and books them directly onto the right rep's calendar in real time.

**AI features, separated from automation with an AI label on it**
Vendor markets several AI-branded features - Chat AI (24/7 visitor qualification and booking), Chili Assist ("build routing rules in plain English"), AI agents for ICP scoring/intent detection, a spam checker, and pre-call meeting prep - but underlying model mechanics are not disclosed publicly; treat as vendor-stated. The core routing engine (queues, round robin, territory rules) is conventional rules-based distribution logic wrapped in a natural-language config layer.

**RevOps role**
Inbound lead-routing plus meeting-booking layer sitting between web forms/CRM and reps' calendars; also positions itself as infrastructure other AI SDR/voice agents call to book meetings end-to-end.

**MCP server**

- **Status bucket**: Official MCP

- **Auth**: Two supported paths, both vendor-documented. Option B: browser OAuth login, admin role required. PulseMCP lists only OAuth; the vendor marketing page lists only the API key. Neither source is wrong, each is partial.
