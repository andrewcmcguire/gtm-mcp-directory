**What it does**
Digital sales room / "Pod" builder for buyer-facing deal collateral, tracking granular buyer engagement (clicks, time-on-page, returning champions) across the deal cycle.

**AI features, separated from automation with an AI label on it**
No independently verified core-product AI/ML claims beyond engagement tracking (which is instrumentation, not AI); the MCP server itself is the standout AI-facing feature, explicitly marketed for "surfacing signals" and "diagnosing deal risk" from an AI client.

**RevOps role**
Buyer-engagement / digital-sales-room signal layer, notable as one of the few tools in this file with both a real free tier AND a free-tier-accessible official MCP server.
