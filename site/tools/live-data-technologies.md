**What it does**
Tracks real-time job changes and employment history for ~80M white-collar professionals by continuously re-verifying identities against open-web and public professional data sources, surfaced via API or the Moneyball/Streams products.

**AI features, separated from automation with an AI label on it**
No ML/LLM claims found on public pages - this is verification/matching infrastructure (300M+ monthly employment verifications, re-verified every 10-14 days), not predictive or generative AI. Aggregation and identity resolution, not AI in the ML sense.

**RevOps role**
Upstream job-change/champion-tracking data source - feeds workflows similar to UserGems/Champify, or can be used directly for warm-outbound triggers.
