MCP Layer tools with an MCP server

The layer that sits between an AI agent and the hundred SaaS apps a GTM team actually runs on: registries that just list servers, and aggregators that host/broker them. The load-bearing question for every entry below is who holds the OAuth tokens when you connect - read `notes` before you wire anything into a production agent. 140 of 145 entries in this category are reachable by an agent: 14 through a server the vendor maintains and 126 through one somebody else built. The category is tagged most often with Proxy tool calls to SaaS apps. See the full category page.
