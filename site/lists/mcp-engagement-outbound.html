Engagement & Outbound tools with an MCP server

The execution layer - sequencers, parallel dialers, and LinkedIn automation tools that actually put messages and calls in front of prospects. MCP maturity here is split sharply: the big sales-engagement platforms (Salesloft, Outreach, lemlist) and several LinkedIn tools have shipped real official servers in 2026, while most parallel dialers and mid-market cold-email tools have none. 81 of 173 entries in this category are reachable by an agent: 23 through a server the vendor maintains and 58 through one somebody else built. The category is tagged most often with Run an email sequence. See the full category page.
