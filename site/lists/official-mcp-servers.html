The 200 GTM tools with an official MCP server

Official means first party. The vendor ships and maintains the server itself, and a wrapper built by Zapier, viaSocket, Composio or any other third party does not count no matter how well it works. 199 of these 200 entries carry a parseable URL in the mcp_url field; the rest claim a server in prose without one, which is recorded as a risk on the methodology page rather than cleaned up quietly. Probed live on 2026-09-04: 27 of the official entries record a URL that answered as an MCP server, and 88 record a documentation page rather than an endpoint. Each tool page says which.
