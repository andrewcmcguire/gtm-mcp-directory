# Which tools can verify an email address is deliverable?

**The short answer**

15 products in this directory are tagged with this job. 12 of the 15 tagged entries have an official MCP server and 2 have a community one, so an agent can call 14 of them directly. 14 are reachable by one person without a contract. Counted 2026-09-04.

Verification is the step between finding an address and sending to it, and skipping it is how a sending domain gets burned. It is also the cheapest step in the chain to automate properly, because the answer is a boolean and the cost of being wrong is asymmetric.

## What this list is not

It is not a ranking and it is not a recommendation. A job tag means the vendor says the tool does this. Nobody here has run any of them: 1 tools in this directory are bench tested. Two tools on the same list can be wildly different in coverage, price and quality, and this directory does not claim to know which.
