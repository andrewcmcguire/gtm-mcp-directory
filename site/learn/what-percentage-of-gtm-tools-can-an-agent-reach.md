# What percentage of GTM tools can an AI agent actually reach?

**The short answer**

67% of the 336 go to market tools counted here have an MCP server of any kind. Applying the second filter, that you can actually get an account without a contract, 168 entries pass both tests, which is 50% of the directory.

## The funnel

| Filter | Entries left | Share of 336 |
|---|---|---|
| Every tool counted | 336 | 100% |
| Has a server of any kind | 225 | 67% |
| Server is first party | 200 | 60% |
| Server, and free or paid self serve | 168 | 50% |
| Server, first party, and free to start | 62 | 18% |
| And somebody here has actually run it | 1 | 0% |

Counted 2026-09-08 from directory.json. The last row is the honest floor of this whole exercise and it is published on the front page rather than buried here.

## Why the last two rows matter most

Every percentage above the last two is a documentation reading. It says a vendor published something and a check found it on a date. The bottom row says somebody ran the thing. This directory's bench tested count is 1, it stays there until Andrew personally runs a tool on a stated date, and no vendor can buy a change to it.

## The direction of travel

Do not read 67% as a permanent state. It is a reading taken on 2026-09-08 from 336 entries whose facts were pulled by hand on 2026-08-24, 2026-08-25, 2026-09-02, 2026-09-03, 2026-09-07. The point of stamping every number with a date is that the next reading is comparable to this one.
