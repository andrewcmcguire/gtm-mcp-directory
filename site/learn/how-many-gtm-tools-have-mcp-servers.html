What the data says

How many GTM tools have MCP servers?

The short answer

415 of the 884 go to market tools counted in this directory have an MCP server of some kind: 200 official and 215 community. 445 had none found on the date they were checked and 15 could not be settled either way.

The whole distribution

StatusEntries ShareWhat it means
Official MCP20023%The vendor ships and maintains the server itself. A wrapper built by Zapier, Composio or a similar third party does not...
Community MCP21524%A working server exists but somebody other than the vendor built it. It can be abandoned without the vendor noticing.
MCP unknown152%The check could not settle it either way. Unknown is a legal answer and it is published rather than guessed.
MCP not applicable91%An MCP server is not a meaningful question for this entry.
No MCP found44550%No server was found at the time of the check. That is a statement about the search, not a promise that none exists.

Counted 2026-09-12. Total: 884 entries across 15 category files, of which 868 are unique products and 16 are the same product listed in a second category.

What none found does not mean

445 entries are none found. That is a statement about a search made on a date, and every entry carries the date its facts were pulled: 71 on 2026-08-24, 22 on 2026-08-25, 121 on 2026-09-02, 15 on 2026-09-03, 107 on 2026-09-07, 548 on 2026-09-12. A vendor who shipped a server the week after their entry was checked is recorded as none found until the next pass. It is not a claim that no server exists.

Why the number is not higher

Adoption is not evenly spread and it is not random. Vendors whose product was already an API shipped servers early: Data & Enrichment is at 42 official of 137, RevOps Infra at 29 of 85. Vendors whose product is a user interface are at the bottom: Enablement & Coaching at 2 of 54 and Forecasting & Revenue at 3 of 22.

The number to watch

This directory rebuilds from source files and republishes the counts each time, so the honest way to read 415 is as a reading taken on 2026-09-12, not a permanent state of the market. The same question asked six months from now will have a different answer, and the point of publishing the date on every number is that you can tell the difference.
