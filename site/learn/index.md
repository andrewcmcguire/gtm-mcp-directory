Every answer here is the answer this directory can actually defend. Where a number appears it was generated at build time from the same 649 entries the rest of the site is built from, and it carries the date it was baked. There are no tool versus tool verdicts anywhere on this site, because 1 tools have been bench tested and a verdict without a test is an opinion wearing a lab coat.

> **How to read these**: A capability list is not a recommendation. A job tag means the vendor says the tool does this, an MCP status means a server was found on a stated date, and an access gate means one person could or could not get in without a contract. Three facts. The choice is still yours.
