How the MCP works

The Clay product entry records an official MCP at clay.com/mcp, with docs at university.clay.com. Auth is a session cookie from app.clay.com, not a scoped API key. The 2026-09-04 probe recorded the URL as a docs page, not a live endpoint. The harvested tool list on that entry was read from a third-party repository (mcp_tools_repo_party is third-party). This page does not treat that catalogue as Clay's own published MCP surface. Tool names and counts are copied from directory.json at build time.

Company honesty_badge is the strongest mcp_status_bucket among linked canonical directory entries, in order official, community, unknown, none-found. n-a is ignored. Mixed products stay visible on the page; the badge does not hide a none-found sibling. Derived badge for this page: official.
