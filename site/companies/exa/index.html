How the MCP works

The Exa product entry records an official first-party MCP server (exa-labs/exa-mcp-server) and a hosted endpoint at mcp.exa.ai/mcp. This is the directory's one BENCH-TESTED entry: a full MCP session on the hosted endpoint was run on 2026-09-03. Auth on the self-hosted server is an API key; the bench test recorded the hosted endpoint serving tools with no credential sent. Tool names and counts are copied from directory.json at build time.

Company honesty_badge is the strongest mcp_status_bucket among linked canonical directory entries, in order official, community, unknown, none-found. n-a is ignored. Mixed products stay visible on the page; the badge does not hide a none-found sibling. Derived badge for this page: official.
