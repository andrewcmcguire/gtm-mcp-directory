How the MCP works

The HubSpot product entry records an official MCP server on the vendor developer page. Auth is OAuth 2.0 on the hosted Remote MCP Server, with a separate local Developer MCP Server that authenticates through the HubSpot CLI. HubSpot Breeze is a second product on the same vendor domain; the directory records mcp_status none-found for that entry. Tool names and counts on this page are copied from directory.json at build time, not typed here.

Company honesty_badge is the strongest mcp_status_bucket among linked canonical directory entries, in order official, community, unknown, none-found. n-a is ignored. Mixed products stay visible on the page; the badge does not hide a none-found sibling. Derived badge for this page: official.
